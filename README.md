This project presents an AI-powered video crime detection system that leverages temporal attention mechanisms to identify critical events in surveillance footage.

The model focuses on important frames over time by assigning dynamic weights using attention, enabling accurate detection of suspicious activities such as fights, theft, and anomalies.

Key Features:
- Temporal Attention for frame importance weighting
- Motion-based saliency detection
- Efficient temporal modeling using advanced architectures (e.g., VideoMAE / Mamba)
- Region masking to reduce background noise
- Improved accuracy in long video sequence analysis

Applications:
- Smart surveillance systems
- Public safety monitoring
- Automated anomaly detection
